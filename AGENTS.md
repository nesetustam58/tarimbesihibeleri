# AgroGrant - Multi-Agent Architecture

## 1. Scraper Agent
- Tarım hibe sitelerini tarar, yeni duyuruları tespit eder ve ham metni ayıklar.

## 2. Matcher Agent (Eşleştirme Ajanı)
- Kullanıcının arazi boyutu, hayvan sayısı ve bölgesine göre uygun hibeleri puanlar.

## 3. Advisory Agent (Danışman Ajan)
- Başvuru şartlarını basitleştirir, gerekli belgelerin kontrol listesini sunar.
